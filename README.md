# GREENLINE Golf Club — scroll demo

Scroll-driven golf club landing: the hero swing is scrubbed by scroll, a 3D golf ball (three.js) launches at the viewer, hops through the sections and hands off to a scroll-scrubbed video where the ball rolls into the hole.

Static site, no build step. Deploy on Vercel with framework preset **Other** (output = repo root).

- `index.html` — the whole site (HTML, CSS, JS)
- `img/` — photos (WebP)
- `frames/hero`, `frames/hole` — video frames for scroll scrubbing

Imagery generated with AI (Figma AI, Seedance). Copy, prices and contacts are demo content.
